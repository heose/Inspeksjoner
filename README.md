# Argus

Offline inspeksjonsapp (PWA) for iPhone. Sjekklister, bilder med markering, avvik, handlinger og PDF-rapport. Alt lagres lokalt på telefonen (IndexedDB).

- `app.js` – sjekklister (øverst i filen), skjema, lagring, PDF-rapport, sikkerhetskopi
- `pdf.js` – liten PDF-skriver uten avhengigheter
- `sw.js` – offline-cache (øk `V` ved ny versjon)

Installer: åpne siden i Safari → Del → Legg til på Hjem-skjerm.
